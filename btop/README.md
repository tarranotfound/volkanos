# btop

Custom btop configuration for Volkanos.

## Included

- `btop.conf` — main btop settings
- `themes/mono-red.theme` — dark Mono Red color theme

## Install

Copy the configuration files into your local btop config directory:

```bash
mkdir -p ~/.config/btop/themes
cp btop/btop.conf ~/.config/btop/btop.conf
cp btop/themes/mono-red.theme ~/.config/btop/themes/mono-red.theme
```

Run btop:

```bash
btop
```
