# Package Notes

Volkanos is primarily intended for Arch Linux, but not every component is required for every setup.

## Core examples

A window manager, terminal, launcher, and status bar are enough for a basic desktop workflow. Audio visualizers, system monitors, editors, and cosmetic tools are optional.

## Package hygiene

Install only components you actually use. Before adding a new dependency:

1. Check whether an existing component already provides the needed feature.
2. Prefer official repositories when they provide a suitable version.
3. Treat AUR packages as optional and inspect their PKGBUILD.
4. Document non-obvious dependencies in the relevant README or setup logic.
