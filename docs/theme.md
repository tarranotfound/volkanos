# Volkanos Theme

Volkanos uses a restrained dark interface with small red and sage-green accents.

## Visual rules

- Dark surfaces with minimal decoration.
- Thin borders instead of thick cards.
- Red is reserved for primary accents and important state.
- Sage green is used for secondary details.
- Typography should remain readable at small sizes.
- Avoid unnecessary glassmorphism and excessive blur.

## Why consistency matters

The same visual language across the terminal, launcher, bar, editor, and system monitor makes the setup feel like one desktop rather than unrelated application themes.
