# Volkanos Neovim

A lightweight Neovim setup designed to match the Volkanos rice.

## Features

- Dark `#1f222d` base
- Red `#e0283b` / `#fc161a` accents
- Sage `#9cbd82` details
- Periwinkle `#556fe6` for functions and special syntax
- JetBrainsMono Nerd Font friendly
- Relative line numbers and cursorline
- Practical window and buffer keymaps
- No plugin manager or heavy dependency stack

## Install

Copy this directory into your Neovim config path:

```bash
cp -r nvim ~/.config/
```

Then launch:

```bash
nvim
```

The configuration is intentionally self-contained. Plugins can be added later without making the base rice dependent on them.
